Import a whole set
Pulls a set's card list from the free catalogue APIs, shows you what's new, and adds the ones you pick. No price-API credits are spent until the nightly run.
Sealed product
Pulls the sealed items the price API actually lists for a set — each set has its own mix, so nothing is assumed. You see what came back before anything is saved.
Bulk and clean-up
Works newest first, because that's where sealed product exists — older and promo sets mostly have none, and each look-up costs a call from an allowance shared with the card catalog and the nightly price run. Sets already checked and found empty are skipped. Safe to re-run: existing products are updated, not duplicated.
